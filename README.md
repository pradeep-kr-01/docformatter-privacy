# DocFormatter AI — privacy policy

This repository exists for one reason: to host the privacy policy at a public
URL, which Google Play requires and a reviewer opens.

It is public because GitHub Pages on a private repository is a paid feature.
It holds the policy and nothing else — the application source is private.

**Published at:** https://pradeep-kr-01.github.io/docformatter-privacy/

`index.html` is generated, not hand-written. The policy is maintained as
Markdown in the application repository (`docs/PRIVACY.md`) and built with
`docs/build-privacy-page.py`. Editing the HTML here directly would leave two
documents making promises about the same software, and the one nobody
remembered to update would be the one being read.
